# Kav & Kev — CRM вэн-продаж (демо)

Демонстрационная CRM для продажи сэндвичей Kav & Kev с машин (вэн-агенты). Построена на базе CRM торговых агентов.

## Что внутри
- **10 машин (Вэн-01…10)**, 600 вымышленных точек: магазины у дома, киоски, супермаркеты, АЗС, кафе/столовые, офисы, буфеты школ и больниц.
- **Ассортимент** — 10 сэндвичей в трёх линейках (Классика / Мясные / Премиум). Названия и граммовки — по открытым каталогам магазинов Бишкека; цены и сроки годности демонстрационные (`src/vanCatalog.js`).
- **🚚 Вэн** — загрузка машины утром → продажи по накладным → возвраты с точек → остаток на склад; sell-through, выручка, нал/QR/отсрочка по машинам и по SKU; загрузочный лист и накладные любого дня.
- **Заявки** — заявки на завтра от агентов и из кабинета клиента, план производства по SKU, загрузка по машинам (+12% запас), статусы: новая → принята → в машине.
- **Возвраты** — по причинам (истёк срок / брак / обмен), по SKU и по точкам, журнал, заявки на возврат из кабинета.
- **Инкассация** — наличные, QR, отсрочка выдана/собрана, сдача кассы, недостачи.
- **Кабинет клиента** (`/cabinet.html`) — точка сама заказывает вне графика визитов и оформляет возвраты, видит свои заявки, поставки и долг.
- Из базовой CRM сохранены: дашборд, клиенты, по линейкам, задачи, календарь, отчёты, динамика, активность, WhatsApp, трекер, команда.
- В карточке точки убраны мастера, Instagram и ассортимент косметики; добавлен блок «Вэн-продажи по точке» (матрица, накладные, возвраты, долг, заявки).

## Демо-режим
- Вход без пароля кнопкой роли: администратор / супервайзер / вэн-агент / клиент (кабинет точки).
- Дата демо зафиксирована — **27.10.2026** (время суток реальное).
- Все данные вымышленные и показываются без размытия.
- Изменения базы отключены. Исключение — заявки и возвраты (вкладка «Заявки», карточка точки, кабинет): создаются, но хранятся в памяти до перезапуска сервера.

## Логотип
Положите файл логотипа в `public/logo.png` — он появится на экране входа, в шапке и в кабинете клиента. Без файла показывается текстовая надпись.

## Запуск
```
npm start            # http://localhost:3000
node scripts/gen_kavkev_demo.js   # пересоздать демо-данные в data/import (необязательно)
```

## Выкладка: GitHub → Render
1. Отдельный репозиторий (например, `kavkev-crm-demo`) → распаковать архив в его папку → опубликовать через GitHub Desktop.
2. Render → New → Web Service → этот репозиторий:
   - Language: **Node**
   - Root Directory: **пусто**
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance type: Free. Постоянный диск не нужен.
3. Первый запуск ~15–20 секунд (генерация треков и посещений). На Free сервис засыпает после 15 минут без посещений.
